# ⚽ Tabela da Premier League 2015–2016

Projeto individual desenvolvido com HTML, CSS e JavaScript que lista todos jogos da temporada 2015–2016 da Premier League.

📌 Sobre o Projeto

Esta aplicação apresenta os placares de todos jogos da temporada 2015–2016, exibindo as principais estatísticas dos clubes de forma organizada e visualmente clara.

A temporada ficou marcada pelo título histórico do Leicester City, considerado uma das maiores surpresas da história do futebol.

🛠️ Tecnologias Utilizadas

HTML

CSS  

JavaScript
